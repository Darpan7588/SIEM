A next-generation Security Information and Event Management (SIEM) platform.

## Planned Features

- Log Collection
- Event Normalization
- Correlation Engine
- Threat Intelligence
- Risk Scoring
- UEBA
- Incident Management
- MITRE ATT&CK Mapping
